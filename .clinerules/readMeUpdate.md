# README Update Rule

Only update `README.md` when the change actually affects how someone uses or sets up the project.

## Update it when:

- A new feature is added
- Setup or install steps change
- New scripts are added
- Env variables change
- Project structure changes significantly
- Something breaks backwards compatibility

## Don't update it for:

- Bug fixes
- Refactors
- Test changes
- Minor UI tweaks
- Performance changes that don't affect usage
